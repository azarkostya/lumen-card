# Lumen Card

Плагин для [Lampa](https://lampa.mx) (Smart TV / Android TV), который перерисовывает карточку
фильма и сериала, достраивает главную и добавляет свои экраны подборок — бесплатная альтернатива
Cardify. Тёплая «дюнная» палитра, полноэкранный кадр, крупный фокус, читаемый с трёх метров.

## Установка

В Lampa: **Настройки → Расширения → Добавить плагин**, адрес:

- **Стабильная** (ветка `main`): `https://azarkostya.github.io/lumen-card/lumen.js`
- **Бета** (ветка `beta`, всё, что ещё не выпущено): `https://cdn.jsdelivr.net/gh/azarkostya/lumen-card@beta/lumen.js`
  — **вместо** стабильного адреса, а не рядом с ним. Старая ветка `feat/lumen-v2` устарела.
