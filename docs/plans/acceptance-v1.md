## Дефекты (переходят в Task 5, Task 6)

1. **Заголовок обрезается** многоточием: «Дюна: Часть…». Unbounded 800 при 5.4em шире, чем влезает одной строкой, а шаблон держит `line-clamp: 1`. В дизайне (экран 01) название целиком. Нужна автоподстройка размера или две строки для длинных названий.
2. **Страна по-английски**: «United States of America». Штатная шапка Lampa пишет «США». `Lampa.TMDB.parseCountries` снаружи недоступен, срабатывает фолбэк на `production_countries[].name`. Нужна локализация (коды ISO через `Lampa.Lang` или текст из штатного `.full-start-new__head`, который `start.js` заполняет до события `complite`).
3. **URL кадра мимо TMDB-прокси**: `https://image.tmdb.org/t/p/w1280//eZ239…jpg` — двойной слэш и прямой хост. Использовать `Lampa.TMDB.image('t/p/w1280' + path)`.
4. **Нет режиссёра** в мета-строке (`· реж. Дени Вильнёв` на экране 01).
5. **Постер скрыт всегда**. По экрану 04 при отсутствии кадра нужен постер 2:3 слева, по экрану 13 — фон из размытого постера при ошибке загрузки кадра.
6. Рейтинги IMDb и КП, «Продолжить» не показаны — ожидаемо: нет CUB-аккаунта, ключа Кинопоиска и истории просмотров. Проверить с подставленными данными в Task 8 и Task 9.
