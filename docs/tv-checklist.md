# Что проверить на живом телевизоре (1.1–1.4)

Список про то, чего в браузере увидеть нельзя: настоящий пульт, внешний плеер, настоящее железо
и сеть. Формат каждого пункта — **шаг → ожидание → факт**. Колонки «Факт», «Дата» и «ТВ» заполняет
тот, кто проверяет: что реально увидел, когда и на каком устройстве (достаточно «Android TV 11,
приставка 2 ГБ» или «Tizen 6, Samsung» — без адресов, серийных номеров и названий домашней сети).
Пустая строка — ещё не проверено. Прежний чек-лист (1.0, разделы 1–16) — в
`docs/tv-checklist-archive-2026-09.md`.

**Не вписывайте в репозиторий** IP-адреса, имена и модели домашней сети, адреса и токены TorrServer
и Jackett, ключи API, адреса почты. Публичный репозиторий.

**Перед началом.** Обновите плагин (закройте Lampa полностью и откройте снова; Pages отдаёт новую
сборку через 2–10 минут после выпуска), в таблице самотеста или в HUD («Показать FPS») убедитесь, что
версия — та, что проверяете. Если шаг не получился — фото экрана телефоном и номер шага; идите к
следующему.

Условные обозначения: **НАС** — Настройки → Lumen Card; **ДОП** — НАС → Дополнительно….

## 1. «Вернуться к просмотру» (1.3)

Продолжение с нужной секунды после перезапуска Lampa во время просмотра во внешнем плеере.

| № | Шаг | Ожидание | Факт | Дата | ТВ |
|---|---|---|---|---|---|
| 1.1 | ДОП → «Пульт и окна»: «Вернуться к просмотру» — вкл (по умолчанию), срок записи 6 ч | пункт есть, включён | | | |
| 1.2 | Откройте фильм с торрентом во внешнем плеере (клиент TorrServer или приложение TorrServe), досмотрите до середины, не закрывая плеер, дождитесь, пока Android выгрузит Lampa (или закройте Lampa принудительно), вернитесь | при запуске Lampa на главной окно «Вернуться к просмотру» с названием фильма | | | |
| 1.3 | В окне выберите «Продолжить» (встроенный клиент TorrServer) | открывается тот же файл с того же места, что и стоял в плеере (допустимая погрешность — несколько секунд), список серий тот же | | | |
| 1.4 | То же, но через приложение TorrServe: кнопка «Открыть раздачу снова» | приложение открывает раздачу; серию и место выбираете там сами | | | |
| 1.5 | Сериал: досмотрите серию до конца, перезапустите Lampa | окно предлагает **следующую** серию | | | |
| 1.6 | Онлайн-источник (не торрент): перезапуск во время просмотра | вместо продолжения — «Открыть карточку» | | | |
| 1.7 | Вернитесь в Lampa штатно (кнопка «назад» из плеера, без перезапуска) | окна нет | | | |
| 1.8 | Запустите после перезапуска **другой** фильм, затем снова перезапустите Lampa | окна нет для прежнего фильма | | | |
| 1.9 | Включите детский режим (НАС → Главная), повторите 1.2 | окна нет | | | |
| 1.10 | Главная → ряд «Досмотреть» | прерванное стоит первым с меткой «Вернуться»; то же в меню по удержанию OK на карточке | | | |
| 1.11 | Выключите пункт 1.1, повторите 1.2 | окна нет | | | |
| 1.12 | Включите HUD («Показать FPS»), посмотрите строку перезапусков | `boot#N · ext M мин назад · cold/ext a/b` — счётчики растут после уходов во внешний плеер | | | |

## 2. Запасной парсер (1.3, по умолчанию выключен)

Нужны два адреса парсера в настройках Lampa и режим «первый» (адреса не вносить в репозиторий).

| № | Шаг | Ожидание | Факт | Дата | ТВ |
|---|---|---|---|---|---|
| 2.1 | ДОП → «Пульт и окна»: «Запасной парсер» | пункт есть, **выключен** по умолчанию | | | |
| 2.2 | Выключен. Сделайте основной (первый) адрес недоступным и откройте «Торренты» у фильма | поведение штатное Lampa: ошибка / пусто, без запасного | | | |
| 2.3 | Включите. Повторите 2.2 | через ~8 с короткое уведомление о запасном парсере, раздачи найдены по второму адресу | | | |
| 2.4 | Основной работает, но ничего не нашёл по редкому запросу | поиск по второму адресу, уведомление | | | |
| 2.5 | Основной работает и находит | запасной не вызывается, уведомления нет | | | |
| 2.6 | Режим парсера «оба» или другой парсер, не Jackett | плагин не вмешивается | | | |
| 2.7 | Задан только один адрес | плагин не вмешивается | | | |

## 6. Окна Lampa в стиле v2 (1.3)

Выбор источника, фильтры, выход, подтверждения. Проверить в обоих стилях (Apple TV и классический) и
при «Оформление меню и окон» = вкл / выкл; отдельно с темой CUB «Neon».

| № | Шаг | Ожидание | Факт | Дата | ТВ |
|---|---|---|---|---|---|
| 6.1 | Карточка → «Смотреть» → выбор источника | окно в стиле v2, фокус читается с дивана, текст не обрезан | | | |
| 6.2 | В окне торрентов — фильтры | то же; рамка фокуса целая, верхний край не срезан | | | |
| 6.3 | «Назад» на главной (окно выхода) и любое подтверждение | то же | | | |
| 6.4 | Полноэкранное окно | без скругления по краям экрана | | | |
| 6.5 | Окно с замком | замок не налезает на текст | | | |
| 6.6 | Меню карточки → вложенное окно → назад | меню остаётся плашкой, не растягивается | | | |
| 6.7 | Тема CUB «Neon» | окна читаются, не сливаются с фоном | | | |
| 6.8 | «Оформление меню и окон» — выкл | окна штатные Lampa | | | |

## 9. Калибровка «Авто» (`perf.samples`)

Пороги автоопределения слабого устройства по телевизору не калибровались: нужны живые замеры.

| № | Шаг | Ожидание | Факт | Дата | ТВ |
|---|---|---|---|---|---|
| 9.1 | НАС → Движение → «Анимации» = «Авто»; перезапустите Lampa, откройте три карточки | вердикт принят; HUD показывает, почему выбран режим | | | |
| 9.2 | В консоли (удалённая отладка) или по HUD: `window.lumen_card.perf.samples()` | список замеров текущей сессии (медиана трёх); запишите числа в колонку «Факт» | | | |
| 9.3 | Если замер ≥ 400 мс | переход на «Лёгкие» с уведомлением; ниже 250 мс — устройство быстрое, режим полный | | | |
| 9.4 | Слабая Android-приставка (память до 2 ГБ) | «Авто» сразу «Лёгкие»; «Полные» только после пяти стабильно быстрых открытий | | | |
| 9.5 | Ручной выбор «Анимации» | перекрывает вердикт «Авто» | | | |

Что прислать по п. 9.2: тип устройства (без модели в публичном репозитории достаточно класса),
объём памяти, три числа замеров, вердикт.

## 11. Снимки B1–B8

Серия снимков для финальной проверки. B1–B3 — с включённой строкой отладки (ДОП → «Для
разработчика» → «Показать FPS»), B4–B8 — без неё. Фото экрана телефоном.

| № | Шаг | Ожидание | Факт | Дата | ТВ |
|---|---|---|---|---|---|
| B1 | Главная, встать на постер первого ряда, **5 секунд ничего не нажимать**, снять на шестой | строка HUD: `fps` около 60, `long` первое число 0 | | | |
| B2 | На главной **зажать стрелку вправо**, снять во время движения | HUD: `fps`, `avg`, `p95` и четыре числа после `raf` с `P` | | | |
| B3 | Открыть сериал «Дораэмон» (поиск Lampa), снять через 3–5 с | HUD: `eps` около 25, `fps` без провала | | | |
| B4 | Выключить HUD. На главной нажать **вниз** один раз | кадр фильма на весь экран и стоит; текст над рядами не сжался; второй ряд встал на место первого, следующий снизу не выглядывает; кадр не погас и не уехал | | | |
| B5 | Листать первый ряд **по одному нажатию** вправо 4–5 раз, фото после каждого | название над рядами меняется сразу логотипом (или сразу текстом) — без мелькания «текст, потом логотип» | | | |
| B6 | Левое меню → «Что посмотреть» → «Крутить», снять во время вращения и после | барабан реально крутится, потом результат | | | |
| B7 | НАС → Внешний вид → «Стиль» → «Apple TV» (выбрать ещё раз), главная целиком | плоский вид; под постерами строка года, «метка · год» в одной строке, год не обрезан | | | |
| B8 | Фильм → «Смотреть» → «Торренты», фокус на **второй** раздаче | рамка фокуса целая, верхний край не срезан | | | |

## Если что-то сломалось совсем

1. Выключите Lumen Card: Настройки → Расширения → отключить плагин → перезапустить Lampa.
2. Если Lampa не стартует — удалите плагин в Расширениях; вернуть можно по адресу из README.
3. Пришлите: версию плагина и Lampa, класс устройства, номер шага из этого списка, фото экрана.
   Адреса и токены своей сети не присылайте.
