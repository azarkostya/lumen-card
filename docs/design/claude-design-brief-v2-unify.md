# Lumen Card — бриф v2: один стиль на всех экранах (Lumen и Apple TV)

Продолжение `claude-design-brief.md`, `claude-design-brief-main.md`, `claude-design-brief-torrents.md`: те же токены
дизайн-системы «Lumen», формат **3840 × 2160**, safe area **160 px слева/справа и 120 px сверху/снизу**
(= 80/60 px на 1920 × 1080 по tvOS HIG), текст не мельче **46 px** (= 23 px на FHD), фокус читается с трёх метров.
Экраны нумеруются с **33**. Рисовать в том же проекте Claude Design на новой странице «v2 — Единый стиль».
**Каждый экран — в двух вариантах рядом на одном артборде: слева «Lumen», справа «Apple TV»** (или два артборда
`NN-L` и `NN-A`).

К брифу приложены скриншоты с реального ТВ (Philips 50″, 20.10.2026):
`tv-tuning/design-review/lumen/*.png` и `tv-tuning/design-review/appletv/*.png` + два отчёта-ревью `REPORT.md`.
Сначала посмотреть их: дизайн должен исправлять то, что видно на снимках, а не придумывать заново то, что уже хорошо.

## 1. В чём проблема

Плагин переоформил главную, героя, верх карточки, хаб «Подборки» и «Что посмотреть» — они на уровне Apple TV / Netflix.
Но всё, что рисует сама Lampa, осталось «лампой»: **поиск, нижняя часть карточки («Актеры», «Комментарии»,
«Рекомендации», «Похожие», штатный ряд серий), экран торрентов, меню по удержанию OK, настройки, левое меню, шапка**.
Отсюда ощущение «два приложения на одном экране»: левая кромка 34 px вместо 80, другой шрифт (SegoeUI Light),
белый фокус-рамка вместо нашего, серые фоны вместо темы, контраст второстепенного текста 1.8–3.5:1.

Задача v2 — **не новый дизайн, а единый**: довести эти экраны до уровня главной в обоих стилях и выровнять
общие элементы (фокус, шапка, типографика, сетка) по всему приложению.

## 2. Два стиля — что их различает

| | «Lumen» (по умолчанию) | «Apple TV» |
|---|---|---|
| Тема | тёплая тёмная (`P.bg` warm), акцент «Песок» | «Глубокая чёрная», акцент «Графит» `#BDB8B2` |
| Шрифт | Golos | Inter (без Display-оптики: на ≥80 px трекинг −0.015…−0.02em) |
| Цвет кадра | акцент и подсветки из постера | «Только фон» — акцент нейтральный |
| Контейнеры | мягкие подложки, карточки | **плоский вид**: контент прямо на фоне, без коробок, разделители тонкими линиями |
| Фокус картинки | масштаб ×1.1 + светлая рамка + мягкая тень | **без рамки**: подъём ×1.14 (2:3) / ×1.09 (16:9), мягкая тень `0 36px 64px rgba(0,0,0,.55)`, подпись уезжает вниз на ~0.35em |
| Фокус текста/кнопок | кремовая заливка `P.text`, тёмный текст | инверсия: белая заливка, чёрный текст; у текстовых блоков — подложка `rgba(255,255,255,.12)` без рамки |
| Подписи под постерами | 500, `P.muted` | Medium 500, secondary |

Общие правила для обоих: **ровно два способа показать фокус** (картинка — масштаб [+рамка в Lumen]; текст/кнопка —
заливка). Сейчас их пять (масштаб+рамка, кремовая заливка, акцент+кольцо у «Крутить», белая заливка, пунктир) — убрать лишние.

- Франшиза: **Голодные игры** (5 фильмов: Голодные игры · И вспыхнет пламя · Сойка-пересмешница. Часть 1 · Сойка-пересмешница. Часть 2 · Баллада о змеях и певчих птицах).

- Поиск: запрос «дюна» — Дюна (2021), Дюна: Часть вторая (2024), Дюна: Пророчество (сериал), Дюна (1984).

  сиды 143; «Отступники / The Departed / 2006 / 4K, HEVC, HDR / BDRemux», 54.2 ГБ, сиды 37.

## 5. Ограничения

1. **Мы переоформляем DOM Lampa, а не пишем свои экраны** для поиска, торрентов, меню и настроек: структура
   (порядок блоков, элементы `.selector` для пульта) остаётся, меняются отступы, шрифты, цвета, размеры, фокус.
   Для каждого такого экрана указать, что «скрыть», что «переставить через CSS (order/flex)», что «перекрасить».
2. **Слабые ТВ** (1,7 ГБ ОЗУ, MediaTek): никаких blur/backdrop-filter на больших площадях, никаких переходов цвета
   фона на полноэкранных слоях (это уже ломало плавность), тени — статичные, в «Лёгких» анимациях без transition.
3. **Контраст:** основной текст ≥4.5:1, крупный ≥3:1 на реальных кадрах (проверять на светлых постерах:
   «Добыча», «Хищник: Убийца убийц») — особенно фокус без рамки в Apple-варианте.
4. **Логотипы сервисов не рисуем** — текстовые метки.
5. **Пульт:** порядок фокуса сверху вниз на карточке сериала — кнопки → ряд серий → описание (сейчас «вниз»
   иногда перепрыгивает серии).
6. **Не трогать то, что работает:** герой главной (контраст 10–12:1), подкраска фона от кадра, сетка постеров
   201/40 px на FHD, хаб «Подборки», «Смотреть по порядку», барабан рулетки, ряд серий 16:9, инверсия кнопок.
7. Итог каждого экрана — с пометкой, **какие токены/правила новые** (чтобы перенести в `src/30_css.js`).
8. **Главная и герой — решение владельца, не подлежит правкам.** Композиция главной остаётся как сейчас всегда:
   размер героя, его поведение при переходе фокуса в ряды, положение рядов, «следующий ряд не выглядывает».
   Никаких Top Shelf-вариантов, сжатия героя, «2,5 ряда» — ни в Lumen, ни в Apple TV. Разрешена только
   полировка внутри (экран 46): типографика, отступы подписей, плавность смены фона.
9. **Клавиатура поиска — штатная трёхрядная Lampa.** Структуру не меняем, только оформление (экран 38).

Что можно менять и чем (для реалистичности дизайна):

| Что | Чем делается |
|---|---|
| Шапка, часы, шрифты, цвета, контраст, левая кромка 80 px (160 на 4K) | CSS поверх элементов Lampa |
| Фокус без рамки в Apple-стиле (подъём + тень) | CSS (тени статичные, проверка плавности на ТВ) |
| Низ карточки: актёры кругами, одна кромка, без белых плашек и панели «ключ API» | CSS + немного JS (скрыть/переставить) |
| Дубль ряда серий, «вниз» на ряд серий | JS плагина |
| Названия в 2 строки, «2 тыс.», неразрывные пробелы, префикс франшизы | JS плагина |
| Торренты, меню по OK (platter у постера), настройки, левое меню | CSS, перекраска и отступы; platter — CSS-позиционирование штатного меню |
| Клавиатура поиска | только оформление, раскладка 3 ряда остаётся |
| Главная и герой | не меняются (п. 8) |
