# Спецификация дизайна — главная (Netflix-стиль), подборки, фишки (экраны 15–32)

> Снято 2026-09-15. Источник: `design/Lumen Home for Lampa - FHD.dc.html` (1920×1080, главный для кода — px÷22.811=em). `- 2K.dc.html`/`- 4K.dc.html` — те же 18 экранов ×1.33/×2, сверено на экране 15 (все величины ровно кратны, новых элементов нет) — отдельно не разбирались. Экраны в файле идут в порядке 15…22, 24, 25, 23, 26…32; ниже — по возрастанию номера. Папка `design/_ds/` не использовалась.
>
> **Правило единиц:** `em = px(FHD-экрана) ÷ 22.811` (база Lampa при 1920×1080; план фазы 1 §0.4). На 16 не делить.
>
> **Масштаб брифа:** `claude-design-brief-main.md` даёт размеры в координатах холста **3840×2160** (4K), а экспорт исполнен в **FHD (1920×1080) = ½ от брифа**. Проверено на 6 независимых величинах — везде точное отношение ×2: safe area 128/**64**, логотип-панель 1400/**700**, описание 1800/**900**, кольцо фокуса 6/**3** px, подъём текста 24/**12** px, «текст ≥40px»→**20px** FHD. В таблицах ниже px — из FHD-файла; где сравниваем с текстом брифа, его число делится на 2.
>
> Обозначения вердиктов: ✓ полностью, ~ частично, ✗ нет/отсутствует в дизайне.
