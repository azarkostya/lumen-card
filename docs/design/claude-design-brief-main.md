# Lumen Card — дополнение к брифу: главная в стиле Netflix и подборки

Продолжение `claude-design-brief.md`: те же токены дизайн-системы «Lumen», тот же формат **3840 × 2160**, safe area 128 px, текст не мельче 40 px, фокус читается с трёх метров. Экраны нумеруются с 15, чтобы не пересекаться с карточкой фильма (01–14). Рисовать в том же проекте Claude Design на отдельной странице «Главная».

## 1. Что меняется

Сейчас главная Lampa — ряды постеров на пустом фоне («Сейчас смотрят», «Сегодня в тренде»), информация о фильме видна только после открытия карточки.

Новая главная работает как Netflix на ТВ:
- **Верхняя половина — герой.** Кадр фильма, на котором сейчас фокус, на весь экран, поверх вуали. Слева логотип фильма (или название шрифтом Unbounded), мета-строка, два ряда описания, рейтинги, статус.
- **Нижняя половина — ряды.** Постеры 2:3 или широкие кадры 16:9, один ряд в фокусе. При движении фокуса по ряду герой меняется: кадр плавно проявляется, текст сменяется с небольшим подъёмом.
- **Подборки — это ряды.** «Рождественские комедии», «Комедии», «Комедии от Netflix», «Сериалы Apple TV+» выглядят как обычные ряды, у заголовка ряда маленькая плашка источника (логотип сервиса или иконка). Любую подборку можно открыть целиком сеткой.

Верхняя панель Lampa (назад, меню, поиск, уведомления, настройки, профиль, полноэкранный режим, часы) — штатная, не переделывается, рисуется поверх героя.

### Откуда берутся подборки (чтобы дизайн не обещал лишнего)

Парсер не нужен: каталог Lampa — это TMDB, а у него есть готовые сущности для всех типов подборок. Каждая подборка в плагине — одна строка описания «тип + идентификатор», из неё строятся и ряд на главной, и сетка, и плитка в хабе.

| Группа | Пример | Источник в TMDB |
|---|---|---|
| Франшизы | Звёздные войны, Гарри Поттер, Джон Уик | коллекция (фильмы) + ключевое слово (сериалы и спин-оффы) |
| Студии и сервисы | Pixar, Ghibli, A24, Netflix, Apple TV+ | компания / телесеть / стриминг-провайдер |
| Темы и настроение | рождественские комедии, зомби, ограбления, космос | ключевое слово + жанр |
| Страны и языки | дорамы, турецкие сериалы, аниме, скандинавский нуар | страна производства + язык + жанр |
| Эпохи | кино 80-х, лучшие 2010-х | диапазон дат + минимум голосов |
| Люди | фильмы Нолана, Тарантино, с Ди Каприо | фильтр по участнику |
| Топы Кинопоиска | Топ-250, «Оскар», семейное | внешний API Кинопоиска, нужен бесплатный ключ пользователя |

Список подборок живёт отдельным файлом-каталогом, который обновляется без переустановки плагина. На главной показываются не все сотни рядов, а выбранные пользователем плюс «умные» (по истории просмотра); полный список — в хабе (экран 24).

## 4. Ограничения

1. **Фон при быстром листании не должен мигать.** Герой меняется только после паузы фокуса 350 мс — это надо показать в раскадровке 23.
2. **Логотипы фильмов есть не у всех.** Везде, где логотип, нужен текстовый фолбэк названием (Unbounded 800, до 2 строк).
3. **Описание грузится с задержкой** (отдельный запрос): в герое предусмотреть скелетон двух строк описания.
4. **Логотипы сервисов (Netflix, Apple TV+) не рисуем** — это чужие товарные знаки; только текстовая метка моно-шрифтом в рамке.
5. **Производительность старых ТВ**: без blur на больших площадях, кроме экрана 22; вуали — градиенты, не фильтры.
6. **Пульт**: всё интерактивное — фокусируемые элементы; вверх с первого ряда уводит на верхнюю панель Lampa, герой не фокусируется.
7. **Постеры приходят 2:3 с TMDB**; широкие 16:9 карточки собираются из кадра (`backdrop_path`) + логотипа.

## 6. Чек-лист

- [ ] Все экраны 3840 × 2160, safe area 128 px, текст ≥ 40 px.
- [ ] Герой не фокусируется, OK на постере открывает карточку (экраны 01–08).
- [ ] У каждой подборки есть «Все N» и экран сетки.
- [ ] Логотип фильма и текстовый фолбэк на одном из экранов.
- [ ] Нет логотипов брендов сервисов, нет эмодзи, иконки только из набора (при необходимости дорисовать «снежинку» в том же стиле: сетка 24, обводка 1.8).
- [ ] Раскадровка 23 показывает задержку смены героя при быстром листании.
- [ ] Хаб подборок (24) читается как каталог, а не как ещё одна главная: плитки крупные, группы-чипы сверху, счётчик подборок.
- [ ] У франшизы (25) видно, что фильмы и сериалы — разные ряды, и есть переключатель порядка.
