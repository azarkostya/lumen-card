# Lumen Card — фишки оформления, навигации и опыта

## Решения (2026-09-15)

Берём всё из списка ниже, кроме двух пунктов, с тремя уточнениями:

- **Не делаем:** «Где смотреть легально» (раздел 5) и цветные кнопки пульта (раздел 3).
- **Ambient-режим:** включается через **3 минуты** бездействия, не через одну. Показывает не постеры, а **ряд красивых кадров известных фильмов** в качестве под экран: 1080p / 2K / 4K. Источник по умолчанию — курируемый список лучших кадров TMDB без текста (у известных фильмов кадры лежат в 3840×2160, размер выбирается по экрану: до 1366 px — `w1280`, иначе `original`); список живёт в манифесте рядом с каталогом подборок и пополняется без обновления плагина. Второй, необязательный источник — свой арт-пак «по мотивам» (пейзажи и атмосферы без персонажей и логотипов), три файла на картинку под три разрешения, хостится вместе с манифестом. Настройкой можно переключить на кадры текущего фильма.
- **Рулетка:** **две отдельные рулетки — для фильмов и для сериалов**, не смешиваются. Перед запуском — **выбор подборок** (одна или несколько чипами, по умолчанию «все»), фильтры «не смотрел» и «есть 90 минут» (для сериалов — «серия до 30 минут»).
- Голосовой поиск — после проверки, есть ли API в Android-клиенте Lampa.

Рабочий список идей. Каждая — с оценкой: **A** дёшево и сразу заметно, **B** средняя, **C** дорого или рискованно. «Данные» — откуда берётся, чтобы не обещать того, чего нет. Помечено «проверить» — нужна живая проверка в Lampa до обещаний.

## 1. Тематические атмосферы

Идея пользователя: фильмам про Хеллоуин — летучие мыши и тыквы, рождественским — ёлки и снег. Делается одним механизмом: **тема определяется по данным фильма, эффект рисуется слоем частиц поверх кадра**.

**Как определяется тема.** Данные: ключевые слова TMDB (`keywords`), жанры, коллекция, месяц выхода, страна. Правила — в отдельном файле-манифесте тем, обновляется без переустановки плагина:

| Тема | Признаки | Эффект поверх кадра | Акцент |
|---|---|---|---|
| Хеллоуин | keywords: halloween, haunted house, slasher; жанр ужасы + октябрь | летучие мыши по дуге, тыквенный тёплый свет снизу, лёгкий туман | тыквенно-оранжевый |
| Рождество | keywords: christmas, santa claus, new year; декабрь | снег, огоньки гирлянды по кромке экрана, ёлочная ветка в углу | тёплый золотой |
| Космос | keywords: space, alien, spaceship; фантастика | звёздная пыль, медленный параллакс | холодный голубой |
| Нуар / детектив | keywords: noir, detective; ч/б | дождь, капли на «стекле», виньетка | стальной |
| Пустыня / вестерн | keywords: desert; «Дюна» | песчаная дымка, дрожание горячего воздуха | песок (текущий) |
| Океан | keywords: ocean, underwater, shark | лучи света сверху, пузырьки | морской |
| Аниме / романтика | жанр анимация + Япония; keywords: cherry blossom | лепестки | розовый |
| Война / боевик | keywords: war, explosion | искры и пепел | медный |
| Зомби | keywords: zombie | помехи, зелёный отсвет | кислотно-зелёный |

**Где показывается.** Карточка фильма (слой между кадром и вуалями), герой главной, плитка подборки в хабе. Частицы — один canvas-модуль с пресетами, не больше 60 частиц, `requestAnimationFrame`, пауза при неактивной вкладке и при трейлере.

**Сезонность.** В октябре хаб подборок сам поднимает «Хеллоуин» первым, в декабре «Рождество», к 9 мая — военные фильмы, к 14 февраля — романтика. **Адвент-календарь** (A): в декабре ряд из 24 «окошек», каждое открывает фильм дня; открытые остаются отмеченными.

**Настройка.** «Тематические эффекты: все / только сезонные / выкл» и автоотключение в режиме «лёгкие анимации». Приоритет **A** для снега и мышей (они самые узнаваемые), остальные темы — **B**, добавляются по одному пресету.

## 2. Оформление

- **Логотипы фильмов вместо текстовых заголовков** (A). Данные: `images.logos` есть у большинства фильмов. Как в Netflix: логотип в карточке и в герое главной, текстовый фолбэк.
- **Акцент от постера** (A). Доминантный цвет постера считается на canvas по уменьшенной копии; «Дюна» становится песочной, «Аватар» синим, «Барби» розовым. Настройка «Акцент: от постера / фиксированный».
- **Ambient-режим** (B). Пульт не трогали 3 минуты (на карточке или на главной) — интерфейс гаснет, идёт слайдшоу курируемых кадров известных фильмов в разрешении экрана (1080p / 2K / 4K), с логотипом фильма мелко в углу, медленным наездом и кроссфейдом 2 с. Любая кнопка возвращает интерфейс на то же место. Красиво на ТВ в гостиной.
- **Переход постер → кадр** (B). При открытии карточки клон постера из ряда «вырастает» в герой, а потом растворяется в кадр. Делается оверлеем поверх штатного перехода Lampa, не трогая её DOM.
- **Скелетоны вместо спиннеров** (A). Описание, отзывы, ряды подборок рисуются серыми плашками, пока грузятся.
- **Метки на постерах в рядах** (A). «Новинка» (вышло < 30 дней), «Скоро» с датой, «Продолжить» с полосой прогресса, «4K». Данные: даты TMDB, `release_quality`, история просмотра.
- **Умный размер заголовка** (уже в плане, Task 5).

## 3. Навигация пультом

- ~~Цветные кнопки пульта~~ — не делаем (решение пользователя).
- **Длинное нажатие OK на постере** (A) — контекстное меню: Трейлер · Вся франшиза · Похожие · В закладки · Скрыть. Lampa даёт `hover:long`.
- **Рулетка «Что посмотреть»** (A, самая «прикольная» фишка). Две отдельные рулетки: **Фильмы** и **Сериалы**. Вход — из хаба подборок, из любой подборки и с главной («Мне повезёт»). Перед стартом: чипы подборок с галочками (несколько сразу, по умолчанию все), фильтры «не смотрел», «есть 90 минут» (у сериалов — «серия до 30 минут»). Постеры крутятся как барабан слот-машины и останавливаются на случайном; итог крупно с кнопками «Смотреть», «Ещё раз», «В закладки».
- **Мини-карта рядов** (B). При удержании ↓ справа появляется вертикальная полоска с названиями рядов, текущий подсвечен; листание ускоряется. Как в Netflix.
- **Прыжок по длинной подборке** (A). Удержание → перескакивает на 10 карточек, ←/→ на первой/последней карточке — на начало/конец.
- **Поиск с подсказками подборок** (B). Ввод «звёзд…» в штатном поиске предлагает «Подборка: Звёздные войны» первым пунктом.
- **Голосовой поиск** (C, проверить наличие API в Android-клиенте Lampa).

## 4. Персональные ряды на главной

Данные: история просмотров Lampa (`Timeline`), закладки, подписки, рекомендации TMDB.

- **«Досмотреть»** — просмотрено 5–95 %, с полосой и «осталось 39 мин» (A).
- **«Потому что вы смотрели Дюну»** — рекомендации TMDB по последним 3 просмотренным (A).
- **«Новые серии ваших сериалов»** — по подпискам и закладкам, дата следующей серии, обратный отсчёт (A).
- **«Скоро на экранах»** — премьеры ближайших 30 дней с датами (A).
- **Профили настроения в одно нажатие** (B): «Вечер пятницы», «Семейный просмотр», «Страшное на ночь», «Есть 90 минут» — заранее собранные фильтры (жанры, возраст, длительность, рейтинг).
- **Скрыть досмотренное** — переключатель для любого ряда (A).

## 5. Информация о фильме

- ~~«Где смотреть легально»~~ — не делаем (решение пользователя).
- **Отзывы без спойлеров** (A, дополнение к Task 9): режим «только заголовки и тон», полный текст — по нажатию.
- **Обратный отсчёт до премьеры** для непросмотренных «Скоро» (A).
- **Хронология франшизы** (B): в карточке фильма из коллекции — ряд «Смотреть по порядку» с номерами и отметками просмотренного.
- **Трейлер по удержанию OK в герое главной** (B), не только в карточке.

## 6. Под капотом, чтобы всё это не тормозило

- **Предзагрузка при фокусе** (A): кадр и логотип фильма грузятся, пока фокус стоит на постере, карточка открывается мгновенно.
- **Кэш подборок 12 часов** (A): главная и хаб открываются без ожидания.
- **Автодетект слабого ТВ** (A): если первая карточка рисовалась дольше 400 мс — режим «лёгкие анимации» включается сам, частицы отключаются.
- **Всё выключаемо** по отдельности в настройках; ничего не мешает штатному Lampa.

## 7. Что не делаем

- Выдуманные «факты о фильме», «бюджет в шутках» — данных нет, будет слоп.
- Логотипы брендов сервисов — только текстовые метки.
- Эффекты поверх плеера — плеер штатный, туда не лезем.
- Больше 60 частиц и blur на весь экран — старые ТВ не вытянут.
