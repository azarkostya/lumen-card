# Спецификация размеров карточки — Lumen Card

> Снято 2026-09-15 на коммите d078194 (до Task 3). Ссылки вида `файл:строка` на `30_css.js` и `40_template.js` могли сдвинуться — искать по содержимому. Кнопки карточки теперь вставляются из оригинала Lampa (`LC.template.build`), их разметку не трогать.

Источник дизайна: `design/Lumen Card for Lampa - FHD.dc.html` (1920×1080, px÷16=em), экраны 01,03,04,05,07(частично),10,13(частично).
Текущая реализация: `src/30_css.js` (CSS-массив, база em=16px), `src/40_template.js`. Нативные значения Lampa (`vendor/lampa/css/app.css`) приведены только как контекст — em там не на базе 16px, сравнение по ним не считается расхождением плагина.

> **Внимание (2026-09-15, после сверки):** колонка «сейчас/Т» в px считалась при базе 16 px, а реальная база Lampa — 22.811 px при 1920×1080 (`body{font-size}` = innerWidth ÷ 84.17). Фактические px текущей реализации в 1.426 раза больше указанных; значения дизайна в px верны. Исполнители переводят px дизайна в em делением на 22.811 и на колонку «сейчас» не опираются.

Обозначения: **Д** — дизайн, **Т** — текущая реализация. Вердикт: ✓ совпадает, ~ приближённо/иначе устроено, ✗ не совпадает / отсутствует.
